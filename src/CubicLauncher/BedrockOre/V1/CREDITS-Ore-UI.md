# Recursos Ore UI

Origen: https://github.com/ninsent/Ore-UI-theme-pack

El README de Ore UI - Icon Pack describe el proyecto como “Minecraft Bedrock inspired”. No se certifica que los gráficos sean recursos oficiales de Mojang.
