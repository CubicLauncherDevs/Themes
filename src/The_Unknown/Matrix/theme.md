# Matrix

Matrix is a dark, cinematic system-console theme for CubicLauncher. Layered charcoal-violet surfaces, thin borders, restrained dusty-violet highlights, and a subdued animated background creating a precise sci-fi interface without the hacker theme that everyone uses.

Inter is used for the primary interface, while JetBrains Mono is reserved for code, logs, terminal output, and technical metadata. The injected CSS adds a matching cursor with a short fading particle trail, crisp focus states, and a very subtle scanline texture over the background.
