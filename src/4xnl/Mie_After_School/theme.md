# Mie After School

A minimalist theme inspired by *Suki na Ko ga Megane wo Wasureta*. It combines the warm light of the original image with cocoa-colored surfaces, powder pink, and ivory text. Mie's glasses appear in the preview and the search icon; the other icons feature soft lines and subtle references to school supplies.

## Credits
Image provided by the user; visible signature “zakizan.” The rights to the illustration and the anime belong to their respective owners. SVG icons drawn for this theme.

## Compatibility
Prepared following https://dev.cubiclauncher.org/docs/es-ES/guias/hacer-themes and verified against the code in the launcher’s “develop” branch. Meta.toml uses root fields and Definition.toml uses root sections, as required by the separate file parser. Statically validated; has not been run within Tauri in this environment.

## Version 1.0.0
No background blur or backdrop blur, including the fixed blur on headers. Microanimations when interacting with sidebar tools and the play button; brief transition when selecting instances. Durations of 140–180 ms, with no continuous decorative animations or permanent `will-change`. Respects the system’s and launcher’s reduced motion preference. Retains functional loading indicators.
